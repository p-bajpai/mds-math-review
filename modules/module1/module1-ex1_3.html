Chain Rule

Symbolic and Automatic Differentiation

In the following questions, we are going to find the derivative of a long chain of functions in two ways. First we will differentiate symbolically, to compute an explicit formula, and then plug in our value of interest. Then, we will emualate automatic differentiation; this is the process by which modern machine learning libraries compute derivatives at a given point.

The function in question is K(x) = (((x2 + 1)2 + 2)2 + 3)2 + 4 and we want to know its derivative at x = -1.

Now define the following additional functions:

  • g(x) = x2 + 2
  • h(x) = x2 + 3
  • k(x) = x2 + 4

Make a note to yourself about their respective derivatives— we will make use of them later.

Phew, that was a lot of work! And the explicit formula in terms of x was quite long, even when we just chained four simple functions together. Thankfully, if we only care about the value of the derivative at a point, there is a better way.

Let f,g,h,k and K be as before and remember f’(z) = g’(z) = h’(z) = k’(z) = 2z.
